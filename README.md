## ✨ Key Features

- **Responsive Design**: fully responsive layout that works beautifully across mobile, tablet, and desktop viewports.
- **Dark/Light Theme**: robust theming system built with CSS variables and Next Themes, persisting user preference.
- **Dynamic Projects Showcase**: detailed case studies for featured projects like TechNest and MediCareX.
- **Accessible & SEO-Friendly**: semantic HTML, accessible navigation, and optimized meta tags.

## 🚀 Featured Projects

### TechNest
A full-stack e-commerce platform for tech products with secure JWT authentication, role-based access control, inventory management, cart, wishlist, coupon system, and PayHere integration.

### MediCareX
A comprehensive pharmacy supply chain platform connecting customers, pharmacists, suppliers, and admins, featuring automated PDF invoice generation, multi-role workflows, and AI content generation using Groq API (Llama models).

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
