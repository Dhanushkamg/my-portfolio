## 🚀 Featured Projects

### 🩸 Suwa Sarana (Blood Donation Platform)
An advanced blood donation platform utilizing geospatial data (PostgreSQL `earthdistance`) to locate nearest eligible donors with real-time SSE/SMS notification cascades. Features trilingual AI Assistants using Groq LLM and AI-assisted fraud triage.

### ⚕️ MediCareX (Healthcare Supply Chain)
A comprehensive pharmacy supply chain platform connecting customers, pharmacists, suppliers, and admins. Features automated PDF invoice generation, secure PayHere payment gateway integration, and automated AI health blog generation.

### 🛒 TechNest (E-Commerce Platform)
A full-stack e-commerce monorepo (Spring Boot & React 19) with OAuth2/JWT authentication, dynamic cart/wishlist management, admin dashboards with full CRUD capabilities, and structured logging.

### 🔗 QuickLink URL Shortener
A modern, high-performance URL shortener application allowing users to convert long URLs into compact links, generate custom aliases, track click analytics, and rate limit APIs using Bucket4j.

## 🚀 Getting Started

To run this portfolio locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dhanushkamg/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
